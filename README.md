# Anni-with-AI-Local-LLM-based-RAG-System-OpenSearch-Streamlit-Docker-
This project delivers a fully offline Retrieval-Augmented Generation (RAG) system using Local LLMs, OpenSearch, and Streamlit, all containerized with Docker. Users can upload PDFs, index them with hybrid semantic + keyword search, and query them through a private, locally powered LLM chatbot.
